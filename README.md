# ربات فروشگاهی تلگرام (پایتون)

یک ربات کامل فروشگاهی تلگرام با پنل ادمین، نوشته شده با کتابخانه `python-telegram-bot`.

## امکانات

### پنل کاربر
- مشاهده دسته‌بندی‌ها و محصولات
- مشاهده وضعیت  هر محصول (موجود / ناموجود)
- دکمه «اطلاع بده وقتی موجود شد» برای محصولات ناموجود — به محض موجود شدن، پیام خودکار برای کاربر ارسال می‌شود
- خرید محصول با کسر خودکار از کیف پول
- مشاهده حساب کاربری (یوزرنیم + آیدی عددی + موجودی)
- شارژ کیف پول: کاربر مبلغ را وارد می‌کند، شماره کارت و نام صاحب کارت نمایش داده می‌شود، بعد از زدن «پرداخت کردم» درخواست برای ادمین ارسال می‌شود
- ارسال تیکت پشتیبانی که مستقیم به آیدی ادمین/پشتیبانی فوروارد می‌شود
- عضویت اجباری در کانال (در صورت فعال بودن از پنل ادمین)

### پنل ادمین (`/admin` یا دکمه «پنل ادمین»)
- مدیریت محصولات: افزودن / ویرایش نام / ویرایش توضیحات / ویرایش قیمت / تغییر وضعیت موجود-ناموجود / حذف
- مدیریت دسته‌بندی‌ها: افزودن / ویرایش / حذف
- مشاهده لیست تمام کاربران با یوزرنیم و آیدی عددی و موجودی، و امکان ویرایش دستی موجودی هرکس
- تنظیم شماره کارت و نام صاحب کارت برای واریزی‌ها
- تنظیم آیدی پشتیبانی
- تایید یا رد درخواست‌های شارژ کیف پول (با یک کلیک، بعد از تایید مبلغ خودکار به حساب کاربر اضافه می‌شود)
- مدیریت عضویت اجباری: تنظیم آیدی/یوزرنیم کانال و لینک عضویت، فعال/غیرفعال کردن

هنگام اجرای اول، هیچ دسته‌بندی یا محصولی از پیش تعریف نشده — همه‌چیز را خودتان از پنل ادمین اضافه می‌کنید.

## نحوه دیپلوی روی Railway

1. یک پروژه جدید در [Railway](https://railway.app) بسازید (Deploy from GitHub repo یا Empty Project + Upload).
2. تمام فایل‌های این زیپ را (بدون هیچ فولدری، مستقیم فایل‌ها) در ریشه‌ی ریپازیتوری/پروژه قرار دهید.
3. در بخش **Variables** پروژه، این متغیرهای محیطی را اضافه کنید:

   | متغیر      | توضیح                                                              |
   |------------|---------------------------------------------------------------------|
   | `BOT_TOKEN`| توکن رباتی که از @BotFather گرفته‌اید                                |
   | `ADMIN_IDS`| آیدی عددی ادمین/ادمین‌ها، با کاما جدا شده. مثال: `123456789,987654321` |
   | `DB_PATH`  | (اختیاری) مسیر فایل دیتابیس، پیش‌فرض `shop.db`                        |

4. Railway به‌صورت خودکار از روی `requirements.txt` پکیج‌ها را نصب می‌کند و طبق `Procfile` / `railway.json` ربات را با دستور `python main.py` اجرا می‌کند.
5. بعد از دیپلوی موفق، در تلگرام به ربات خود پیام `/start` بدهید.
6. با آیدی عددی که در `ADMIN_IDS` گذاشته‌اید، دستور `/admin` را بزنید تا پنل ادمین باز شود.

### نکته مهم درباره‌ی ذخیره‌سازی اطلاعات (دیتابیس)

این ربات از **SQLite** استفاده می‌کند که اطلاعات را در یک فایل ذخیره می‌کند. فضای دیسک پیش‌فرض روی Railway ممکن است در هر ری‌دیپلوی (deploy) پاک شود. برای اینکه اطلاعات کاربران/محصولات همیشه باقی بماند:

1. در پروژه Railway یک **Volume** بسازید (از بخش سرویس، Add Volume).
2. Volume را روی یک مسیر مثل `/data` مونت کنید.
3. متغیر محیطی `DB_PATH` را برابر `/data/shop.db` قرار دهید.

اگر این کار را انجام ندهید، ربات همچنان کار می‌کند اما در صورت ری‌دیپلوی شدن پروژه، اطلاعات ذخیره‌شده ممکن است از بین برود.

### آیدی عددی و یوزرنیم کانال برای عضویت اجباری

- ربات باید در کانال مورد نظر **ادمین** باشد تا بتواند عضویت کاربران را بررسی کند.
- برای «آیدی کانال جهت بررسی عضویت» می‌توانید یوزرنیم کانال (مثل `@mychannel`) یا آیدی عددی کانال (مثل `-1001234567890`) را وارد کنید.
- برای «لینک کانال» باید یک لینک واقعی و قابل کلیک بدهید (مثل `https://t.me/mychannel`) تا دکمه عضویت برای کاربر نمایش داده شود.

## اجرای محلی (تست روی سیستم خودتان)

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن ربات شما"
export ADMIN_IDS="آیدی عددی شما"
python main.py
```

## ساختار فایل‌ها

| فایل                | توضیح                                                        |
|---------------------|----------------------------------------------------------------|
| `main.py`           | نقطه شروع ربات و ثبت تمام هندلرها                              |
| `config.py`         | خواندن متغیرهای محیطی (توکن، آیدی ادمین‌ها)                    |
| `db.py`             | تمام توابع دیتابیس (SQLite)                                    |
| `state.py`          | مدیریت وضعیت مکالمه برای دریافت ورودی متنی از کاربر/ادمین      |
| `keyboards.py`      | ساخت کیبوردهای شیشه‌ای ربات                                    |
| `user_handlers.py`  | منطق بخش کاربر عادی                                            |
| `admin_handlers.py` | منطق کامل پنل ادمین                                            |
| `requirements.txt`  | پکیج‌های موردنیاز پایتون                                       |
| `Procfile`          | دستور اجرای ربات برای Railway                                  |
| `railway.json`      | تنظیمات دیپلوی Railway                                          |

موفق باشید! در صورت نیاز به تغییرات بیشتر (مثل اضافه کردن عکس محصول یا درگاه پرداخت آنلاین)، کد کاملاً قابل توسعه است.
